# Copilot_Demo
This repo demonstrates how to work with Copilot directly in VS Code

---

## Overview:
Working with Copilot directly in VS Code is an efficient workflow that can assist developers in streamlining their tasks. It also challenges devs to put on their project-manager hats and review the code written by Copilot.

---

## Advantages:
It's neat to be able to assign tasks to Copilot directly on the GitHub site, but working with it in VS Code allows a developer to work on a project or issue ***line-by-line***. When collaborating with Copilot in VS Code, a developer can watch in real time as it provides new code, or makes any edits to existing files. You can also approve or deny the edits right *inside* your code editor. Instead of having to go back and forth via commenting and issue-creation, you can tweak code on the spot until you're satisfied with it, and then commit it and push it to the repo when you're ready.

---

## Key Takeaways:
Copilot (and AI in general) is an incredibly advantageous tool that developers can (and should) use to streamline their workflows whenever possible. It can reduce downtime, especially when it comes to tackling menial tasks (*like basic contact forms!*), and aid a developer in debugging their code.
